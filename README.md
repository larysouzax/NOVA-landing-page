# Nova Landing Page

Landing page moderna e responsiva criada com HTML, CSS e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Você pode abrir o arquivo `index.html` diretamente no navegador.

Também pode usar a extensão **Live Server** no VS Code.

## Personalização

Edite no `index.html`:

- Nome/logo `NOVA`
- Textos da página
- Link do GitHub
- E-mail de contato

Edite no `style.css`:

- `--primary`
- `--secondary`
- `--bg`

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve.

Seu site será publicado em um endereço parecido com:

`https://seuusuario.github.io/nome-do-repositorio/`
