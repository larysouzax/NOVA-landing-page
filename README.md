

# 🚀 Nova Landing Page

Uma landing page moderna, responsiva e desenvolvida com foco em **design clean, organização de código e experiência do usuário**.

O projeto foi criado utilizando **HTML, CSS e JavaScript puro**, com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end e construir um projeto para portfólio no GitHub.

## 💻 Sobre o projeto

A **Nova Landing Page** apresenta uma interface moderna com seções bem definidas, efeitos visuais, layout responsivo e navegação simples.

O projeto pode ser utilizado como base para páginas institucionais, portfólios, produtos, serviços ou outros tipos de landing pages.

## ✨ Funcionalidades

* Layout moderno e responsivo
* Menu adaptado para dispositivos móveis
* Navegação suave entre as seções
* Cards com efeitos de interação
* Seção de apresentação
* Seção de recursos
* Seção sobre o projeto
* Área de chamada para ação
* Rodapé com ano atualizado automaticamente
* Design adaptado para desktop, tablet e celular

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts

## 🚀 Como executar

Clone o repositório:

```bash
git clone URL-DO-SEU-REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd landing-page-github
```

Depois, abra o arquivo:

```text
index.html
```

Você também pode utilizar a extensão **Live Server** no VS Code para visualizar o projeto localmente.
